# Glossary

Shared terminology for ChatGPT and Claude. A new term is added here first.
The "Russian" column is a reference for translating sources and for chat with the lead only;
documents use the English term.

| Term | Russian | Definition / Notes | Source |
|---|---|---|---|
| Datasheet | Даташит | Document describing a component's characteristics | — |
| Reference manual | Справочное руководство | Description of MCU peripherals and registers | — |
| ISR (Interrupt Service Routine) | Обработчик прерывания | — | — |
| HAL (Hardware Abstraction Layer) | Уровень абстракции оборудования | — | — |
| Task spec | ТЗ | Task specification (Lite/Full) written by ChatGPT, reviewed by Claude, see `docs/tasks/` | AGENTS.md |
| Lead | Руководитель | The human coordinating the project | AGENTS.md |
| Brief | Бриф | Context for ChatGPT written by Claude before the task spec, `work/<project>/` | AGENTS.md |
| Skill | Скилл | Reusable local procedure for Claude Code, `.claude/skills/` | AGENTS.md |
