# MEMORY.md — Project Knowledge

Specifics of working with the project repositories, shared by all agents.
Read after [AGENTS.md](AGENTS.md), before any work in a repository.

**Entries are added, changed or removed only on the user's request** (AGENTS.md, section 7).

## Entry format

- One entry per fact, under the section of its repository (or "General" if it applies to all).
- Each entry: date (`YYYY-MM-DD`), the fact, and why it matters / how to apply it.
- English only.

Example:

```
- 2026-11-05 — `make flash` fails if the board is on a USB hub.
  Connect the board directly to the host.
```
